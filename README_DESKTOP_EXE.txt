BOOK ASSET CSV ENTRY FILLER - DESKTOP & STANDALONE EXE
=========================================================

Option 1: Build the Standalone .exe (No Python required to run once built)
--------------------------------------------------------------------------
1. Double-click "build_exe.bat".
2. It automatically sets up PyInstaller and builds "ChapterAssetFiller.exe".
3. Once completed, you have a single ChapterAssetFiller.exe file you can share
   with anyone on Windows to run with a simple double-click!

Option 2: Run directly with Python without building .exe
--------------------------------------------------------
- Double-click "run_desktop.bat" OR
- Open terminal and run: python chapter_asset_app.pyw

Command-line usage:
-------------------
python fill_chapter_assets.py input.csv asset_folder output.csv
